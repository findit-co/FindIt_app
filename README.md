## FIND IT

FIND IT is a desktop app built with Python and Tkinter that helps users discover how to turn common local resources into profitable ventures. Unlike generic object-identification or recycling apps, FIND IT focuses on **value extraction, local relevance, and income generation**.

### Why this app exists

Most apps tell you:
- "What is this object?"
- "How do I recycle it?"

FIND IT asks a different question:
"How can I make money from this?"

### Key features

-  Resource matching – Enter any resource name (text input)
-  Local intelligence – Choose Lagos, Aba, or Kano for location‑specific suggestions
-  Business ideas – Get actionable ways to turn resources into products or services
-  Income estimator – See approximate monthly earnings (e.g., ₦50,000/month)
-  Search history – All queries saved to CSV and displayed in a dashboard

Screens

1. Welcome / Home
2. Input (text + location dropdown)
3. Results (uses, business ideas, income)
4. Dashboard / History (previous searches from CSV)

 Tech stack

- Python 3.x
- Tkinter (GUI)
- CSV (file-based storage)

 Project structure

This was a team project with clear role allocation:
- App Controller & Integration
- Home / Input / Results Screens
- Resource Engine (CSV matching)
- Data Storage & Dashboard


**Note:** This project was built for educational purposes to demonstrate GUI development, file handling, multi-screen navigation, and team-based integration.
